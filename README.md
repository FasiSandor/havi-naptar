# HAVI NAPTÁR

Mobil- és iPad-központú 4 hetes / havi naptár.

## Vercel környezeti változók

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `NEXT_PUBLIC_BASE_URL`

A `NEXT_PUBLIC_BASE_URL` értéke a production URL legyen, például:
`https://havi-naptar.vercel.app`

Google OAuth callback:
`https://<production-domain>/api/google/callback`


## Aktuális verzió

v2 – rugalmas 1/2/4 hetes, havi és egyedi dátumtartomány; nagyított napi idővonal; 15 perces eseménymozgatás és időpontcsere.
